# oracle_guided_search/

The exact search, spent more carefully: `deflate-strictly` commits to one
candidate at a time so a *no* comes with a proof rather than a spent budget,
and `enumerate-subspaces` generates each candidate subspace once per symmetry
class instead of once per member. `price-canonical-route` is the instrument
that says what that canonical generation costs before an hour is spent on it.

Which questions these answer that `decide-rank` does not:
[`../OPTIONS/one-question-per-command.md`](../OPTIONS/one-question-per-command.md);
their flags:
[`../OPTIONS/committing-to-candidates.md`](../OPTIONS/committing-to-candidates.md).
The division of labour is at the top of [`CMakeLists.txt`](CMakeLists.txt),
and the numbers that retired `find-at-rank` to the `rejected-experiments`
branch stay in [`measurements/`](measurements/README.md).
