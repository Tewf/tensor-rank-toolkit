# OPTIONS/

The flag tables, one page per question, plus the four pages that come before
any table, covering the thirteen tools sharing this argument grammar
([`one-question-per-command.md`](one-question-per-command.md)). The front
door and index is [`../OPTIONS.md`](../OPTIONS.md); this folder is its pages.

In this folder, the four to read first:

- [`one-question-per-command.md`](one-question-per-command.md): the one thing
  each tool answers that no other does.
- [`precedence-and-tunables.md`](precedence-and-tunables.md): flag beats
  file beats compiled default, and where the file is looked for.
- [`common-recipes.md`](common-recipes.md): the lines people actually type.
- [`one-idea-several-spellings.md`](one-idea-several-spellings.md): where two
  tools spell one idea differently.

And the tables: [`searching-for-rank.md`](searching-for-rank.md),
[`asking-a-sat-solver.md`](asking-a-sat-solver.md),
[`committing-to-candidates.md`](committing-to-candidates.md),
[`bounding-from-a-curve.md`](bounding-from-a-curve.md),
[`sparsifying-operators.md`](sparsifying-operators.md),
[`building-maps.md`](building-maps.md),
[`reading-the-answer-off.md`](reading-the-answer-off.md).

Example of use: you wondered what `--target` does to `decide-rank`, so you
open [`searching-for-rank.md`](searching-for-rank.md) and read its row, which
carries the default and the measurement that chose it. Lost entirely?
[`../start-here.md`](../start-here.md) first.
